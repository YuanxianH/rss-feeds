# AI RSS

Many AI labs and companies don't offer RSS. This project checks those sites on a schedule, turns new papers, posts, and releases into feeds, and lists them in one directory. Updates run about once an hour.

Open the directory to see every source, then click RSS to subscribe:

[yuanxianh.github.io/rss-feeds](https://yuanxianh.github.io/rss-feeds/)

The code is public. You can subscribe to this list, or add more sources yourself.
