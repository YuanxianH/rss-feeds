# AI RSS

很多 AI 实验室和公司的网站没有 RSS。这个开源项目会定时去这些网站上看，把新论文、新文章、新模型做成 Feed，放在一个目录里，大约每小时更新一次。

Many AI labs and companies don't offer RSS. This project checks those sites on a schedule, turns new papers, posts, and releases into feeds, and lists them in one directory. Updates run about once an hour.

订阅目录 / Directory: [yuanxianh.github.io/rss-feeds](https://yuanxianh.github.io/rss-feeds/)

在目录里点 RSS 即可订阅，也可以把下面的地址加进阅读器。  
Click RSS in the directory, or add the URLs below to your reader.
